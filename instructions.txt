## Duration / time columns (IMPORTANT)
Many duration fields are stored as VARCHAR times like '00:53:45' (HH:MM:SS), NOT as numbers.
This includes logged_hours and all AAFS / break columns when they look like HH:MM:SS.

NEVER do any of these on duration columns:
- COALESCE(column, 0)
- AVG(column)
- SUM(column)
- column + column
- comparing them directly as ints

ALWAYS convert HH:MM:SS varchar durations to seconds before math:

  DATEDIFF(SECOND, 0, TRY_CAST(NULLIF(LTRIM(RTRIM(column)), '') AS TIME))

Use TRY_CAST so bad/null values become NULL instead of failing.
Treat NULL durations as 0 seconds with COALESCE(..., 0) ONLY after converting to seconds.

To show an average/total back as HH:MM:SS:

  CONVERT(varchar(8), DATEADD(SECOND, CAST(ROUND(avg_seconds, 0) AS int), 0), 108)

Example - average total break for one person in July 2026:

SELECT
  userName,
  CONVERT(varchar(8), DATEADD(SECOND, CAST(ROUND(AVG(
    COALESCE(DATEDIFF(SECOND, 0, TRY_CAST(NULLIF(LTRIM(RTRIM(aafsBreak)), '') AS TIME)), 0)
    + COALESCE(DATEDIFF(SECOND, 0, TRY_CAST(NULLIF(LTRIM(RTRIM(aafsLunchBreak)), '') AS TIME)), 0)
    + COALESCE(DATEDIFF(SECOND, 0, TRY_CAST(NULLIF(LTRIM(RTRIM(aafsShortBreak)), '') AS TIME)), 0)
    + COALESCE(DATEDIFF(SECOND, 0, TRY_CAST(NULLIF(LTRIM(RTRIM(aafsPersonalTime)), '') AS TIME)), 0)
  ), 0) AS int), 0), 108) AS avg_total_break,
  COUNT(*) AS session_count
FROM EmployeeAttendance
WHERE userName LIKE '%Harzh%Mevada%'
  AND sessionDate >= '2026-07-01'
  AND sessionDate < '2026-08-01'
GROUP BY userName;

If a duration column is already numeric (float/int hours), then AVG(column) is fine. Prefer TRY_CAST-to-TIME when values look like HH:MM:SS.

These columns represent time spent away from the computer performing work-related activities.
Values are typically VARCHAR HH:MM:SS durations.
Activities include:
- aafsConferenceCall
- aafsTraining
- aafsMeeting
- aafsWorkReview
- aafsUnknownTafs
- aafsItDeskSupport
- aafsTeamMeeting
- aafsOfficefunactivity
- aafsDocumentMgmt
- aafsSalesCall
- aafsNamesOnBoard
- aafsOnDeskSupport
- aafBaqHseq
- aafsInterview
When users ask about activities, meetings, training, conference calls, support work, interviews, or time away from the system, return the appropriate AAFS values.
Ignore activities with zero time unless the user specifically asks to see every activity.

## Breaks
The following four columns are employee break categories (VARCHAR HH:MM:SS):
- aafsBreak
- aafsLunchBreak
- aafsShortBreak
- aafsPersonalTime
Whenever a user asks about:
- Breaks
- Break time
- Average break
- Total breaks
- Break summary
- Time spent on breaks
Always:
1. Convert each break column to seconds before adding or averaging.
2. Total Break Time (in seconds) =
   break_seconds + lunch_seconds + short_break_seconds + personal_seconds
3. For averages, AVG the total seconds across matching sessionDate rows, then convert back to HH:MM:SS.
4. When useful, also show each break category's average separately.
5. Include COUNT(*) as session_count so the user knows how many days were averaged.
